Complete Setup Guide

Note: This guide covers installation, configuration, and getting started with React Native Mantine.

Installation

Step 1: Install the Package

# Using npm
npm install react-native-mantine

# Using yarn
yarn add react-native-mantine

# Using pnpm
pnpm add react-native-mantine

Step 2: Install Peer Dependencies

# Install required dependencies
npm install expo-linear-gradient expo-font expo-clipboard

# Or with yarn
yarn add expo-linear-gradient expo-font expo-clipboard
Important: These peer dependencies are required for full functionality.

Basic Configuration

Step 1: Wrap Your App with ThemeProvider

import { ThemeProvider } from 'react-native-mantine';

export default function App() {
  return (
    <ThemeProvider>
      {/* Your app content */}
    </ThemeProvider>
  );
}

Step 2: Start Using Components

import { Button, Text, Stack } from 'react-native-mantine';

function MyComponent() {
  return (
    <Stack spacing="md">
      <Text size="xl" weight={700}>
        Hello React Native Mantine!
      </Text>
      <Button variant="filled" color="blue">
        Click Me
      </Button>
    </Stack>
  );
}

Custom Theme Configuration

You can customize the default theme to match your brand:

import { ThemeProvider, createTheme } from 'react-native-mantine';

const myTheme = createTheme({
  primaryColor: 'blue',
  primaryShade: 6,
  fontFamily: 'System',
  colors: {
    // Override or add custom colors
  },
  fontSizes: {
    xs: 12,
    sm: 14,
    md: 16,
    lg: 18,
    xl: 20,
  },
  spacing: {
    xs: 4,
    sm: 8,
    md: 16,
    lg: 24,
    xl: 32,
  },
});

export default function App() {
  return (
    <ThemeProvider theme={myTheme}>
      {/* Your app */}
    </ThemeProvider>
  );
}

Using Theme in Components

import { useTheme } from 'react-native-mantine';
import { View, Text } from 'react-native';

function ThemedComponent() {
  const theme = useTheme();

  return (
    <View style={{
      backgroundColor: theme.colors.blue[6],
      padding: theme.spacing.md
    }}>
      <Text style={{
        color: theme.white,
        fontSize: theme.fontSizes.lg
      }}>
        Themed Component
      </Text>
    </View>
  );
}

TypeScript Support

React Native Mantine is built with TypeScript and provides full type definitions:

import { ButtonProps, TextProps } from 'react-native-mantine';

interface MyButtonProps extends ButtonProps {
  customProp?: string;
}

function MyButton({ customProp, ...props }: MyButtonProps) {
  return <Button {...props} />;
}

Common Patterns

Form Example

import {
  Stack,
  TextInput,
  PasswordInput,
  Checkbox,
  Button
} from 'react-native-mantine';

function LoginForm() {
  return (
    <Stack spacing="md" padding="lg">
      <TextInput
        label="Email"
        placeholder="your@email.com"
        required
      />
      <PasswordInput
        label="Password"
        required
      />
      <Checkbox label="Remember me" />
      <Button fullWidth>Sign In</Button>
    </Stack>
  );
}

Modal Example

import { useState } from 'react';
import { Modal, Button, Text } from 'react-native-mantine';

function ModalExample() {
  const [opened, setOpened] = useState(false);

  return (
    <>
      <Button onPress={() => setOpened(true)}>
        Open Modal
      </Button>

      <Modal
        opened={opened}
        onClose={() => setOpened(false)}
        title="Confirmation"
      >
        <Text>Are you sure?</Text>
      </Modal>
    </>
  );
}

Best Practices

  • Always wrap your app with ThemeProvider
  • Use useTheme() hook to access theme values
  • Leverage TypeScript for better type safety
  • Use consistent spacing with theme values
  • Prefer theme colors over hardcoded values
  • Use semantic color names (primary, success, error, etc.)

Troubleshooting

Module not found errors

Make sure all peer dependencies are installed:

npm install expo-linear-gradient expo-font expo-clipboard

Theme not applying

Ensure ThemeProvider wraps your entire app at the root level.

TypeScript errors

Update your TypeScript version to 5.0+ and ensure strict mode is enabled.
