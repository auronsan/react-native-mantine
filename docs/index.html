Why React Native Mantine?

📦

70+ Components

Comprehensive collection of components organized by functionality - from basic buttons to complex overlays and navigation.

🎨

Powerful Theme System

Extensive customization with color schemes, variants, sizes, and a complete design system for consistent UIs.

💪

TypeScript First

Built with TypeScript 5.2.2 in strict mode with comprehensive type definitions for all components.

🚀

Production Ready

Thoroughly tested and battle-tested components ready for production mobile applications.

🎯

Consistent API

Familiar API patterns across all components inspired by the popular Mantine web library.

⚡

Zero Dependencies

Minimal peer dependencies - just React Native, expo-linear-gradient, expo-font, and expo-clipboard.

Get Started

Installation

# Using npm npm install react-native-mantine # Using yarn yarn add react-native-mantine # Using pnpm pnpm add react-native-mantine

Quick Start

import { ThemeProvider, Button, Text, Stack } from 'react-native-mantine'; export default function App() { return ( <ThemeProvider> <Stack spacing="md"> <Text size="xl" weight={700}> Welcome to React Native Mantine </Text> <Button variant="filled" color="blue"> Get Started </Button> </Stack> </ThemeProvider> ); }
