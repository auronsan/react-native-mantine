AUTOMATIC DOCUMENTATION DEPLOYMENT
===================================

┌─────────────────────────────────────────────────────────────────────┐
│                        DEVELOPER WORKFLOW                            │
└─────────────────────────────────────────────────────────────────────┘
                                  │
                                  │ git push origin main
                                  ▼
┌─────────────────────────────────────────────────────────────────────┐
│                         GITHUB ACTIONS                               │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  Workflow: deploy-docs.yml                                   │   │
│  │  ─────────────────────────                                  │   │
│  │                                                              │   │
│  │  Step 1: Checkout Repository                                │   │
│  │          └─ actions/checkout@v4                             │   │
│  │                                                              │   │
│  │  Step 2: Setup GitHub Pages                                 │   │
│  │          └─ actions/configure-pages@v4                      │   │
│  │                                                              │   │
│  │  Step 3: Upload Artifact                                    │   │
│  │          └─ actions/upload-pages-artifact@v3                │   │
│  │          └─ Source: ./docs                                  │   │
│  │                                                              │   │
│  │  Step 4: Deploy to GitHub Pages                             │   │
│  │          └─ actions/deploy-pages@v4                         │   │
│  │                                                              │   │
│  │  ⏱️  Total Time: ~1 minute                                   │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘

                                  │ Deployment Complete

==============

│

│   ├── README.md                  │ Documentation

│   └── CNAME                      │ Custom domain
│
├── .github/
│   ├── workflows/
│   │   ├── deploy-docs.yml        │ Auto deployment
│   │   └── deploy-showcase.yml    │ Manual showcase
│   │
│   ├── DEPLOYMENT_SUMMARY.md      │ Architecture doc

│   └── README.md                  │ GitHub docs
│
├── scripts/

│
├── DEPLOYMENT.md                   │ Full guide

└── README.md                       │ Updated
